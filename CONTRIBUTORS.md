## How to Contribute

We welcome contributions of all kinds! Please see our [Contributing Guidelines](CONTRIBUTING.md) for details on:

- Reporting bugs
- Suggesting features
- Submitting code changes
- Improving documentation
- Testing and quality assurance

## Recognition

Contributors are recognized in several ways:

1. **Listed in this file** - All contributors are acknowledged here
2. **Git history** - Your commits are preserved in the repository history
3. **Release notes** - Significant contributions are highlighted in release notes
4. **Community** - Active contributors may be invited to join the core team

## Support the Project

If you find this project useful, you can support it by:
